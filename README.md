# 本地搜题（souti-app）

Android 本地题库搜题工具。将题库导入手机后，可在微信小程序、网课、PDF 等其他 App 的做题页面直接调出悬浮按钮，框选题目并离线识别、比对，结果以悬浮卡片覆盖在当前页面上，无需在两个 App 之间切换。

## 当前版本功能

### 题库管理

- 题库存入手机本地 IndexedDB，不上传服务器。
- 支持 Excel（`.xlsx` / `.xls`）、JSON、CSV、TXT 文件导入。
- 自动识别常见表头及别名，包括“题目 / 问题 / 试题 / 题干”和“答案 / 正确答案 / 参考答案”。
- Excel 可解析题目、选项与答案；结果卡片会显示答案对应的选项内容，例如 `B. 保护接地`，而非只显示字母。
- 导入后建立本地检索索引，支持删除并重新导入题库。

### 跨 App 截图搜题

- 首次使用申请 Android 系统录屏权限，授权成功后显示“授权成功”。
- 授权在本次 App 服务会话内持续有效；每次搜题不会重复弹出录屏授权。
- 可在任意 App 页面显示小型悬浮搜索按钮；按钮无外层蓝色方块，支持按住拖动，并记住最后停留位置。
- 点击悬浮按钮后才出现截图框，拖拽调整范围并确认搜索；授权本身不会自动弹出截图框。
- 截图框、识别状态和搜索结果都显示在当前做题页面上方，不会跳回本 App。
- 结果卡片可关闭后继续做题，也可再次点击悬浮按钮继续搜索。

### 离线识别与匹配

- 使用 Android 原生 **ML Kit 中文文字识别**，避免 WebView 中 Tesseract Worker 在连续后台识别时卡住的问题。
- 对截图裁剪区域进行中文 OCR，再调用本地题库的模糊匹配。
- 文本会先归一化，并采用二元组倒排索引预筛、Dice 相似度、包含关系与编辑距离综合排序，返回最匹配的题目。
- 搜索结果展示：题目、匹配度、答案、答案对应内容，以及完整选项（如题库中存在）。
- 答案文字可长按选择和复制；点击复制后会显示“复制成功”。

## 使用方式

1. 安装 APK 后打开“题库管理”，导入 Excel 或其他题库文件。
2. 回到“搜题”页，开启悬浮窗与录屏权限。首次授权完成会提示“授权成功”。
3. 打开微信小程序或其他做题 App；屏幕上会保留可拖动的搜索按钮。
4. 点击按钮，框选题目和选项区域，点击搜索。
5. 在原做题页面上直接查看匹配题、答案及答案内容；需要时长按答案文字复制。

## 技术结构

- **前端**：Vite + 原生 JavaScript + Capacitor
- **本地题库**：IndexedDB + SheetJS（Excel 解析）
- **匹配引擎**：文本归一化、倒排索引与综合相似度排序
- **Android 原生层**：Java、MediaProjection 前台服务、系统悬浮窗
- **OCR**：Google ML Kit 中文文字识别（`text-recognition-chinese`）

## 本地构建

环境要求：Node.js、Android SDK、Java 21。

```powershell
npm install
npm run build
npm run cap:sync
Set-Location android
.\gradlew.bat assembleDebug
```

调试 APK 位于：`android/app/build/outputs/apk/debug/app-debug.apk`。

## 题库格式

- **Excel**：推荐首行使用“题目”“选项A”“选项B”“选项C”“选项D”“答案”；也兼容常见同义表头。
- **JSON**：`[{"question":"...","answer":"..."}]`，字段也接受 `q` / `a`。
- **CSV**：第一列题目、第二列答案，可带表头。
- **TXT**：奇数行题目、偶数行答案，成对出现。

示例见 `sample/题库示例.json`。

## 已知边界

- OCR 结果受字号、清晰度、旋转角度与遮挡影响；框选时尽量包含完整题干和选项。
- 当前匹配基于文本相似度，不是语义问答；题目改写过多可能降低命中率。
- 录屏和悬浮窗依赖 Android 系统权限；系统结束前台服务或用户手动关闭权限后，需要重新开启。
- 当前重点支持 Android；iOS 的跨 App 屏幕读取受系统限制，尚未实现。
